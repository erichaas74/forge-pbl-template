# Voyage visual assets

Created 2026-09-15 using Codex's built-in image generation. Six finished 1536 × 1024 images were converted from PNG to WebP (quality 88; ship alpha preserved). The conversion changes encoding only. No external image pack or remote asset dependency is required.

## Prompt set / art direction

Shared direction: cinematic painted historical adventure game environment, plausible early-sixteenth-century materials, dramatic natural light, deep water in the foreground for an independently rendered ship, detailed scenery at middle and far distance, no text, logos, modern objects or UI. Illustrative reconstruction, not documentary evidence.

| File | Scene brief |
| --- | --- |
| `island.webp` | Atlantic island anchorage at golden hour, rugged green volcanic headlands, sheltered turquoise water and a distant beach; open foreground sea. |
| `storm.webp` | Dangerous Atlantic coast under dark storm clouds, sun breaking through rain, steep rocky headland and rough foaming sea; open foreground water. |
| `river.webp` | Tropical Brazilian river mouth opening into the Atlantic, dense forest and sandbars, inviting golden light, open water foreground for a ship. |
| `market.webp` | West African coastal exchange scene near Elmina, inhabited shoreline with boats, barrels and market activity, distant stone fort, palms and hills, clear water foreground. |
| `harbor.webp` | Early-sixteenth-century Lisbon harbor, warm stone waterfront and terracotta roofs, harbor activity and atmospheric hills, water foreground. |
| `ship.webp` | Detailed early-sixteenth-century wooden expedition ship as a separate transparent sprite, side three-quarter view with bow left, stern right, rigging and two bare square yards, no main canvas sails, no sea or ground; sails will be added by the game renderer. |

The ship's canvas, damage, stitching, barrels, cargo timber, wake and navigation lines are authored procedural game elements. The existing geographic atlas is retained outside this asset directory.

These are student-facing illustration assets. Historical source interpretation uses the separately labeled project evidence, never inferred details from generated scenery.
